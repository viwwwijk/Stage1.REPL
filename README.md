# Эмулятор языка оболочки ОС (вариант №12)

Практическая работа №1 по дисциплине «Конфигурационное управление».

## Общее описание

Эмулятор имитирует работу в командной строке UNIX-подобной ОС.
Приложение реализовано в виде графического интерфейса на `tkinter`:
верхняя область — вывод, нижняя строка — ввод команды, выполнение по
нажатию `Enter`. Введённая строка дублируется в области вывода с
приглашением `$`, чтобы получался диалог с пользователем.

Текущее состояние — **этап 1 (REPL)**. Команды `ls` и `cd` являются
заглушками: они печатают своё имя и переданные аргументы. Виртуальная
файловая система подключается на этапе 3.

## Структура проекта

```
src/
  main.py              точка входа
  emulator/
    parser.py          разбор строки на команду и аргументы
    commands.py        выполнение команд
    gui.py             графическое окно и цикл REPL
tests/                 модульные тесты (unittest)
run.sh / run.bat       скрипты запуска
```

## Описание функций и настроек

Параметров командной строки на этапе 1 нет — они появляются на этапе 2
(путь к VFS и путь к стартовому скрипту).

### `emulator.gui`

| Функция | Назначение |
| --- | --- |
| `get_username()` | имя пользователя текущей ОС, при ошибке `unknown` |
| `get_hostname()` | имя машины, при ошибке `unknown` |
| `build_title()` | заголовок окна вида `Эмулятор - [username@hostname]` |
| `EmulatorApp.print_line(text)` | вывод строки в текстовую область |
| `EmulatorApp.print_error(error)` | вывод сообщения об ошибке |
| `EmulatorApp.on_enter_pressed(event)` | обработчик нажатия `Enter` |
| `EmulatorApp.run_line(line)` | разбор и выполнение одной строки |
| `EmulatorApp.run()` | запуск цикла обработки событий окна |

Заголовок окна формируется из реальных данных ОС через `getpass` и
`socket`, а не из настроек приложения.

### `emulator.parser`

| Функция | Назначение |
| --- | --- |
| `parse_line(line)` | список аргументов строки с учётом кавычек |
| `split_command(tokens)` | разделение на имя команды и аргументы |

Поддерживаются одинарные и двойные кавычки: они группируют символы в
один аргумент и в результат не попадают, поэтому `cd "my dir"` даёт
один аргумент `my dir`. Незакрытая кавычка вызывает `ParserError`.

### `emulator.commands`

| Функция | Назначение |
| --- | --- |
| `execute(command, args)` | выбор и выполнение команды |
| `execute_exit(args)` | завершение работы, аргументы недопустимы |
| `execute_stub(command, args)` | вывод имени команды и её аргументов |

Неизвестная команда и неверные аргументы вызывают `CommandError`,
которая перехватывается окном и печатается в область вывода.

## Сборка и запуск

Внешние зависимости отсутствуют, нужен Python 3.8+ с модулем `tkinter`
(в Debian/Ubuntu ставится пакетом `python3-tk`).

```sh
./run.sh          # Linux и macOS
run.bat           # Windows
```

Запуск тестов:

```sh
PYTHONPATH=src python3 -m unittest discover -s tests
```

## Примеры использования

```
$ ls
ls: аргументы отсутствуют
$ ls -l "my folder" file.txt
ls: аргументы: -l, my folder, file.txt
$ cd 'папка с пробелом'
cd: аргументы: папка с пробелом
$ cd "unclosed
ошибка: незакрытая кавычка "
$ mkdir test
ошибка: неизвестная команда: mkdir
$ exit now
ошибка: exit не принимает аргументов
$ exit
```

Последняя команда закрывает окно эмулятора.
